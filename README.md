# Epilepsy EEG Classification


Автоматизированное распознавание эпилептической активности по данным ЭЭГ с использованием **Time Series Transformer**.

## 📋 Особенности проекта

- **Мультимодальная архитектура:** Time Series Transformer + клинический MLP-блок (синергия двух источников информации).
- **Строгая валидация:** стратификация по субъектам, Leave-One-Subject-Out (LOSO), бутстрэп‑интервалы для всех метрик.
- **Калибровка вероятностей:** изотоническая регрессия (Brier score 0.023), позволяющая интерпретировать предсказания как риск патологии.
- **Комплекс стресс‑тестов:** Shuffle Test, изоляция клинического признака, визуализация Grad‑CAM.
- **Воспроизводимость:** фиксированный random seed, единый пайплайн для всех архитектур, сохранённые чекпоинты.

## 📊 Результаты финальной модели (TST Clinical)

| Метрика | Значение (95% ДИ) |
|---------|-------------------|
| ROC AUC | 0.981 |
| Accuracy | 0.944 (0.932–0.955) |
| Precision | 0.920 (0.893–0.948) |
| Recall | 0.890 (0.859–0.920) |
| F1‑score | 0.905 (0.885–0.925) |
| Brier score | 0.023 |

LOSO (Leave‑One‑Subject‑Out): средняя Accuracy на новых пациентах — 0.76, медиана — 0.96.
